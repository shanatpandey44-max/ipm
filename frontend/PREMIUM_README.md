## 🎨 Design System

### Colors
- **Brand Blue**: `#00A3E0` (IPM blue)
- **Brand Ink**: `#0B2545` (deep navy)
- **Gold Accent**: `#D4AF37` (luxury gold)
- **Surface**: `#F7F9FC` (light background)

### Typography
- **Display Font**: Fraunces (serif)
- **Body Font**: Inter (sans-serif)

### Animations
- `fade-up`: Section reveal animation
- `float`: Floating element animation
- `shimmer`: Gradient text animation
- `pulse-glow`: Glowing effect animation
- `scale-in`: Scale in animation
