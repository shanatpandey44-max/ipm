# Deployment Notes

This repository contains a combined frontend and backend app.

## Build & Start
1. Install dependencies and build frontend:
   ```bash
   npm install
   npm start
   ```

2. `npm start` runs the backend server from `backend/index.js`.

## Railpack Support
If Railpack requires a script or a root-level build file, ensure this repo has a root `package.json` and `Procfile`.
